## Описание проекта

## Лабораторной работы по изучению принципов «Инфраструктура как код» (Infrastructure as Code, IaC) и автоматизации управления конфигурациями. 

# 

## Работа разделена на две части:

### 1\. Terraform: Декларативное управление локальной контейнерной инфраструктурой Docker (создание образов, запуск контейнеров, проброс портов, параметризация через переменные).

### 2\. Ansible: Автоматизированная настройка управляемых узлов по протоколу SSH (написание плейбуков, установка пакетов на удаленные серверы, использование inventory).

# 

## Структура репозитория

### \- `task1\_terraform/` — конфигурационные файлы Terraform.

### &#x20; - `main.tf` — основная конфигурация провайдера Docker, образов и ресурсов.

### &#x20; - `variables.tf` — входные переменные инфраструктуры.

### &#x20; - `outputs.tf` — выходные данные (ID контейнеров и образов).

### \- `task2\_ansible/` — конфигурационные файлы Ansible.

### &#x20; - `inventory.ini` — файл инвентаризации с описанием управляемых серверов.

### &#x20; - `playbook.yml` — сценарий установки системных утилит (`curl`, `nano`).

# 

## Требования для запуска

### Для локального запуска необходимо установить:

### \- Подсистему Windows для Linux (WSL, например Ubuntu)

### \- Docker Engine

### \- Terraform (v1.9.8)

### \- Ansible \& sshpass

# 

## Краткая инструкция по запуску

# 

### Задание 1 (Terraform)

### Перейдите в папку `task1\_terraform/` и выполните инициализацию, а затем развертывание:

### ```bash

### cd task1\_terraform

### terraform init

### terraform apply

### ```

### Для удаления созданной инфраструктуры:

### ```bash

### terraform destroy

### ```

# 

### Задание 2 (Ansible)

### Перед запуском Ansible необходимо поднять локальные Docker-контейнеры, имитирующие серверы (`server1` и `server2` на базе `alpine`), и настроить SSH-пароли.

# 

### Перейдите в папку `task2\_ansible/`, проверьте доступность узлов и запустите плейбук:

### ```bash

### cd task2\_ansible

### ansible -i inventory.ini servers -m ping

### ansible-playbook -i inventory.ini playbook.yml

### ```
